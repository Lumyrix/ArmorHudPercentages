A complementation for [ArmorHUD-Percentages](https://modrinth.com/project/wF189hn9) that displays durability percentages(%) above the armor slot.

The percentages will only be shown if the ArmorHUD-Percentages config value "Show Warning" is set to "ON".

A keybind is provided to toggle the warning (and by extension, the numbers) separately from the HUD.
